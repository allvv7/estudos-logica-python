# 🚀 Estudos de Lógica e Colaboração Open Source

Repositório desenvolvido como parte do desafio prático **"Utilizando Recursos do GitHub em um Projeto Open Source"** da formação **GitHub Certification** na [DIO](https://www.dio.me/).

## 🎯 Objetivo
Demonstrar na prática o uso dos recursos colaborativos do GitHub:
- Gestão de tarefas com **GitHub Projects (Kanban)**
- Registro de melhorias com **Issues**
- Desenvolvimento isolado em **Branches**
- Revisão e integração via **Pull Requests**
- Documentação centralizada na **Wiki**

## 🛠️ Tecnologias & Ferramentas
- Git & GitHub
- Python 3
- GitHub Projects & Wiki
